# 7-1 Final Project – 3D Scene (OpenGL)

## Overview
This project is a 3D scene created using C++ and OpenGL. The goal was to design and build a scene using basic shapes, textures, lighting, and camera controls. The final result is a fully navigable environment that builds on previous milestones.

---

## Design Approach

### How do I approach designing software?
I approach design by first breaking the problem into smaller parts. For this project, that meant identifying the objects in the scene, how they relate to each other, and what functionality was required. I focused on structure first, then visuals.

### What new design skills has your work on the project helped you to craft?
This project helped me get better at spatial thinking and planning object placement in a 3D environment. I also improved at organizing code so that transformations, materials, and rendering logic were separated and reusable.

### What design process did you follow for your project work?
I followed a step-by-step process:
- Start with basic shapes and layout
- Add transformations (scale, rotation, position)
- Refine camera controls and navigation
- Introduce textures and materials
- Implement lighting


Each step built on the previous one, which made the project manageable.

### How could tactics from your design approach be applied in future work?
Breaking problems into smaller steps and building incrementally is something I can apply to any software project. It helps reduce errors and makes debugging easier.

---

## Development Approach

### How do I approach developing programs?
I focus on getting a simple version working first, then improving it. I test frequently and make small changes instead of trying to do everything at once.

### What new development strategies did you use while working on your 3D scene?
I relied more on modular functions, such as separating scene setup from rendering. I also paid closer attention to how transformations and matrices affect objects, which helped avoid confusion when positioning objects.

### How did iteration factor into your development?
Iteration was a big part of this project. I constantly adjusted object placement, lighting, and scaling. Small changes made a noticeable difference, so testing and refining was important throughout.

### How has your approach to developing code evolved throughout the milestones?
Earlier in the course, I focused more on just getting things to work. By the end, I was more intentional about organization, readability, and reusability. I also became more comfortable debugging visual issues.
